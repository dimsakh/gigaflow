# Сборка GigaFlow для Windows

## Требования

- Windows 10/11 x64;
- Python 3.12 x64;
- [Inno Setup 6](https://jrsoftware.org/isinfo.php);
- интернет для установки Python-зависимостей.

Модель распознавания в сборку не входит.

## Сборка

Откройте PowerShell в корне репозитория:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install . pyinstaller==6.14.2
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m PyInstaller packaging\GigaFlow.spec --noconfirm --clean
& "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" "packaging\GigaFlow.iss"
```

Готовый установщик: `installer-output\GigaFlow-Setup.exe`.

## Что входит в установщик

PyInstaller собирает приложение в каталог `dist\GigaFlow`. Inno Setup упаковывает
этот каталог в установщик для текущего пользователя. Python, pip и отдельная
установка библиотек пользователю не нужны.

Не включаются модель GigaAM, пользовательская история, настройки, логи,
виртуальные окружения, исходный репозиторий и служебные папки Codex.

## Проверка на чистой Windows

1. Установить `GigaFlow-Setup.exe` без Python.
2. Проверить ярлыки рабочего стола и меню «Пуск».
3. Запустить из пути, содержащего пробелы и кириллицу.
4. Убедиться, что появляется статус загрузки модели.
5. После загрузки проверить модель в пользовательском кэше Hugging Face (обычно `%USERPROFILE%\.cache\huggingface\hub`).
6. Перезапустить приложение без интернета: повторной загрузки быть не должно.
7. Проверить микрофон, `Ctrl+Shift+Space`, вставку текста и меню системного трея.
8. Завершить через «Выйти» в трее.
9. Удалить через «Установленные приложения».

## Известные ограничения

- Полную проверку микрофона, системного трея и глобальной горячей клавиши нельзя
  выполнить в безголовой среде GitHub Actions; необходим ручной тест Windows.
- Установщик не подписан сертификатом Authenticode, поэтому SmartScreen может
  показать предупреждение.
- Первая загрузка модели требует доступа к официальному источнику, используемому
  `onnx-asr`, и может занять несколько минут.
- Корпоративные политики Windows могут блокировать глобальные горячие клавиши,
  микрофон, автоматическую вставку или запуск неподписанного приложения.
