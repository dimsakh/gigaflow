# GigaFlow для Chrome

Отдельный локальный голосовой ввод для рабочего компьютера. Расширение показывает
индикатор прямо на странице и вставляет распознанный текст в активное поле. Голос
обрабатывается локальной моделью GigaAM-v3 и не отправляется в облако.

## Установка

1. Перенесите всю папку `chrome-gigaflow` на рабочий компьютер.
2. Запустите `Установить Chrome GigaFlow.cmd`.
3. Откройте `chrome://extensions`.
4. Включите «Режим разработчика».
5. Нажмите «Загрузить распакованное расширение» и выберите папку `extension`.
6. Закрепите GigaFlow на панели Chrome при желании.

Установщик добавляет локальный помощник в автозагрузку текущего пользователя.
Права администратора для этого не нужны. На компьютере должен быть установлен
Python 3.12–3.14. При первой установке нужен интернет для библиотек и модели.

Компания может запретить режим разработчика или локальные расширения своей
политикой Chrome. В таком случае потребуется разрешение системного администратора.

## Использование

- Поставьте курсор в поле на сайте.
- Нажмите `Alt+Shift+Space` или кнопку расширения.
- Продиктуйте текст и сделайте паузу примерно две секунды.
- Текст вставится в то же поле. Одновременно он сохраняется в буфере Windows.

Горячую клавишу можно поменять на странице `chrome://extensions/shortcuts`.

В меню расширения доступны три режима очистки:

- выключена;
- мягкая — запинки, «э-э», «эм», начальное «ну» и повторы;
- полная — дополнительно «значит», «типа», «как бы», «грубо говоря» и похожие
  обороты, когда они используются как вводные.

Расширение не работает на служебных страницах Chrome (`chrome://...`), в магазине
Chrome и на страницах, где корпоративная политика запрещает внедрение расширений.
