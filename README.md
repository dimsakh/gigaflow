# GigaFlow

GigaFlow — локальный голосовой ввод для Windows на базе Sber GigaAM-v3.

## Что умеет

- запускает и останавливает запись глобальной клавишей `Ctrl+Shift+Space`;
- показывает плавающий индикатор звука и черновую расшифровку;
- распознаёт русскую речь локально;
- автоматически вставляет готовый текст в окно, где была запущена диктовка;
- одновременно оставляет готовый текст в буфере обмена для ручной вставки;
- умеет мягко или полностью убирать слова-паразиты и речевые запинки;
- хранит локальную историю диктовок без сохранения аудио;
- если автоматическая вставка недоступна, позволяет вставить текст обычным `Ctrl+V`.

## Установка для пользователя Windows

1. Откройте страницу **Releases** этого репозитория и скачайте
   `GigaFlow-Setup.exe` из последнего выпуска.
2. Запустите установщик. Python, pip и командная строка не нужны.
3. Оставьте включённым создание ярлыка рабочего стола или запускайте GigaFlow
   из меню «Пуск».
4. При первом запуске дождитесь статуса «Модель готова». Модель загружается из
   официального источника, используемого `onnx-asr`, и сохраняется в
   `%LOCALAPPDATA%\GigaFlow\models`.
5. После успешной загрузки интернет для распознавания не нужен, а при следующих
   запусках модель повторно не скачивается.

Если загрузка не удалась, GigaFlow покажет понятное сообщение. Проверьте интернет
и перезапустите приложение. Удаление доступно в разделе «Установленные приложения»
Windows.

Для тестовых сборок без выпуска откройте **Actions → Windows installer**, выберите
успешный запуск и скачайте artifact `GigaFlow-Windows-Installer`. Внутри находится
`GigaFlow-Setup.exe`.


## Управление

- `Ctrl+Shift+Space` — начать диктовку.
- Черновой текст начинает появляться примерно через секунду после начала речи.
- После речи сделайте паузу около двух секунд: запись завершится сама, а текст
  попадёт в буфер.
- Повторное нажатие `Ctrl+Shift+Space` завершает запись немедленно.
- Чтобы сменить сочетание, нажмите поле «Горячая клавиша», а затем нажмите
  нужные клавиши физически. Вводить их название текстом не требуется.
- В поле «Очистка слов-паразитов» выберите «Мягкая», «Полная» или «Выключена».
- Кнопка в главном окне — то же действие.
- Запустите диктовку в поле, где стоит курсор: после распознавания текст вставится туда автоматически.
- Если окно не разрешило автоматическую вставку, появится сообщение «Скопировано» — тогда нажмите `Ctrl+V`.

Текстовая история хранится в `%LOCALAPPDATA%\GigaFlow`. Аудиозаписи не сохраняются.

## Разработка

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m gigaflow
```

Тесты:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Известные ограничения

- Установщик пока не подписан Authenticode; Windows SmartScreen может показать
  предупреждение о неизвестном издателе.
- Первая загрузка модели занимает несколько минут и требует интернет.
- Микрофон, глобальные горячие клавиши и автоматическая вставка могут быть
  ограничены корпоративной политикой или программами безопасности.
- Служебные страницы и приложения с повышенными правами могут запрещать
  автоматическую вставку; распознанный текст при этом остаётся в буфере обмена.
- Подробности ручной сборки и чек-лист проверки приведены в
  [BUILD_WINDOWS.md](BUILD_WINDOWS.md).
